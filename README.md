## 📖 درباره پروژه | About the Project

### 🇮🇷 فارسی
کارگاه تعاملی **Git و GitHub** از صفر تا انتشار پروژه.  
اسلایدهای زنده با دستورات، تمرین عملی، شاخه و ادغام، Pull Request، Release و خروجی نهایی یک مخزن واقعی روی GitHub.

### 🇬🇧 English
An interactive **Git & GitHub** workshop from zero to project release.  
Live slides covering commands, hands-on practice, branching & merging, Pull Requests, Releases, and a real public repository as the final deliverable.

## 🚀 نحوه استفاده | How to Use

### 🇮🇷 فارسی
1. از **Live Demo** باز کن، یا فایل `index.html` را دانلود و در مرورگر باز کن  
2. با کلیدهای `←` `→` یا دکمه‌های پایین بین اسلایدها حرکت کن  
3. تمرین‌های داخل اسلایدها را روی سیستم خودت انجام بده  

### 🇬🇧 English
1. Open the **Live Demo**, or download `index.html` and open it in your browser
